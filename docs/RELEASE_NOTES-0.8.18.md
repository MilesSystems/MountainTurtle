# Mountain Turtle 0.8.18 Preview

- Setup now works before Python is installed. The tools installer includes Python,
  rechecks availability without restarting, and offers Add your first drive.
- Drives show queued uploads, active uploads, cached changes, and unavailable
  status explicitly. No pending uploads requires a complete local check.
- Retry queued uploads without ejecting the drive or removing cached files.
- Show the next connection retry and Retry now; resume retries after wake or
  restored network access while preserving working mounts and ejected drives.

This Preview is signed with an Apple Development certificate and authenticated
with the existing Sparkle update key. It is not Developer ID signed or notarized.
